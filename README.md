# My C++ Development Portfolio

Welcome to my repository! This is a curated collection of my independent C++ projects, focusing on algorithms, custom cryptography, and core game development mechanics.

📁 Repository Structure
---

1. 🏦 [Bank](./Bank)
   A financial transaction and multi-currency wallet simulation program.
   - **Key Concepts:** State ledger initialization, flow control logic, and interactive console menu systems.
   - **Status:** Complete & Fully Documented.

2. 🎮 [Boss Fight Game Engine](./BossFightGame)
   A modular, console-based turn-based combat simulation.
   - **Key Concepts:** Dynamic game loops, enemy scaling logic, and condition-based state validation.
   - **Status:** Complete & Fully Documented.

3. 🗺️ [Dungeon Game](./Dungeon-Game)
   A text-based procedural dungeon crawler engine with graph-based navigation.
   - **Key Concepts:** Node-based map routing, nested database tracking, and turn-based interactions.
   - **Status:** Complete & Fully Documented.

4. 🔐 [Simple Text Encryptor](./Encryption)
   A lightweight cryptography application featuring an original substitution cipher.
   - **Key Concepts:** Associative arrays (`std::map`), dynamic token string parsing, and random noise injection.
   - **Status:** Complete & Fully Documented.

5. 📦 [Huffman Text Compressor](./Huffman-text-compressor)
   A data optimization utility utilizing a simulated prefix code frequency structure.
   - **Key Concepts:** Character frequency counting, algorithmic tree weights, and bit-stream translation.
   - **Status:** Complete & Fully Documented.

6. 🧮 [Math Expression Parser](./Math-expression-parser)
   A sequential algebraic expression evaluator maintaining operator precedence scales.
   - **Key Concepts:** Standard token parsing via buffers, multi-pass validation arrays, and division-by-zero checks.
   - **Status:** Complete & Fully Documented.

7. 👥 [Mini Social Network](./Mini-social-network)
   A structural network graph simulator mapping relational user edge connections.
   - **Key Concepts:** Graph adjacency vector models, bidirectional sync tracking, and intersection algorithms for suggestions.
   - **Status:** Complete & Fully Documented.

8. 🧠 [Movie Recommendation Engine](./Recommendation)
   An automated taste profile catalog delivering matches using collaborative filtering.
   - **Key Concepts:** Multidimensional sparse arrays, matrix intersection weights, and conditional fallback logic.
   - **Status:** Complete & Fully Documented.

9. 🎒 [RPG Inventory System](./Rpg-Inventory)
   A clean state-tracking database managing player inventory metrics.
   - **Key Concepts:** Command split-buffer tokenization, multi-layered lookups, and modifier logic caps.
   - **Status:** Complete & Fully Documented.

10. ⛓️ [Simple Blockchain Console](./Simple-blockchain)
    A functional cryptographic ledger reproducing block validation algorithms.
    - **Key Concepts:** Proof-of-work puzzle constraints, pending transaction mempool caching, and immutable hash line links.
    - **Status:** Complete & Fully Documented.

11. 🔢 [Text Calculator](./Text-Calculator)
    A linguistic expression interpreter converting text string digits to mathematical values.
    - **Key Concepts:** String parsing data maps, dynamic token stream splitting, and bi-directional lookups.
    - **Status:** Complete & Fully Documented.
